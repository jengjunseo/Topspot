# T.O.P. — ANOTHER DIMENSION ARCHIVE

T.O.P.의 첫 정규 앨범 《TOP SPOT — ANOTHER DIMENSION》과 그 앞의 시간을 연결하는 비공식 문화 아카이브입니다. 사실 기록, 당사자 발언, 보도, 편집자의 해석을 구분합니다.

## 기능

- 매 방문 전체 화면 인트로, 공식 영상 배경과 사용자 제공 포스터 대체 이미지
- ENTER를 누른 뒤 시작하는 배경 음악과 화면을 이동해도 유지되는 음량·음소거 설정
- RECORDS: 프롤로그 작업, 세 개의 전시실, 11곡 목록, 공식 스트리밍 링크
- THE LIFE: 출처 링크가 있는 15개 기록, 연도 필터, 관련 트랙 연결
- INDEX / SEARCH: 곡과 연표를 브라우저 안에서 검색하고 유형별로 필터
- 트랙 상세: Apple Music 미리듣기 상태 안내, 공식 가사·곡 정보 링크, 곡별 해석, 연결된 연표와 출처
- Apple Music 미리듣기: 재생을 눌렀을 때 트랙 번호별 URL을 조회하고, 미제공·조회 실패·브라우저 재생 실패를 구분
- 키보드 검색 단축키 /, 곡 화면의 좌우 화살표 이동, 모션 줄이기 설정

## 로컬에서 열기

정적 파일만 사용하며 빌드 단계나 패키지 설치가 필요하지 않습니다. index.html을 직접 열거나, 작업 폴더에서 정적 서버를 실행하세요.

    python -m http.server 8000

그 다음 http://localhost:8000을 엽니다. 일부 브라우저는 file://에서 외부 미리듣기 API 요청을 제한할 수 있어 정적 서버 실행을 권장합니다.

## 콘텐츠 편집

- content.js: 앨범 정보, 트랙 정보·감상 노트, 15개 연표 기록과 출처
- app.js: 화면 렌더링, 탐색, 검색, 미니 플레이어, 인트로와 배경 음악 제어
- styles.css: 반응형 화면과 접근성 스타일
- docs/CONTENT-SOURCES.md: 사실 확인에 사용한 자료
- docs/ASSET-SOURCES.md: 이미지 및 권한 상태

트랙 해석은 아카이브의 관점으로 표시됩니다. 확인하지 못한 크레딧이나 공개 권한이 불분명한 자료를 추정해 추가하지 않습니다.

## 미디어와 개인정보

인트로의 MP3와 JPG는 사용자가 제공한 파일입니다. 두 파일의 저작권 및 공개 배포 권한은 확인되지 않았으며, JPG도 공식 앨범 아트워크나 인물 사진이라고 표시하지 않습니다. 영상은 YouTube에서 임베드하고, 영상이 막히거나 늦으면 JPG를 배경으로 보여 줍니다. 가사 전문과 공식 앨범 아트 파일은 저장소에 넣지 않습니다.

검색어는 서버로 보내지 않습니다. 배경 음악 음량과 음소거 설정은 localStorage에 저장됩니다. 배경 음악은 ENTER를 누른 뒤 재생됩니다. Apple Music 미리듣기는 이용자가 재생을 선택했을 때 Apple의 조회 API를 요청합니다. 해당 트랙의 미리듣기가 없거나 조회·재생에 실패하면 상태를 구분해 표시하고 공식 Apple Music·Spotify 링크를 제공합니다.

## 배포

배포 대상은 [jengjunseo/Topspot](https://github.com/jengjunseo/Topspot) 저장소와 기존 Vercel `topspot` 프로젝트입니다. 이 프로젝트는 루트에 `index.html`이 있는 정적 사이트이며 빌드 명령이나 패키지 설치 없이 제공할 수 있습니다.
